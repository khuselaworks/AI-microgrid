# Solar data preparation results

These figures and reports show how sunlight and temperature readings were filtered, gaps filled and values averaged. Start with `ghi_raw.png`, `temp_raw.png` and the corresponding `filtered_*.png` figures.

`ghi_w_m2` means global horizontal irradiance (sunlight on a horizontal surface), measured in W/m². `temperature_c` means temperature in °C. Each filename identifies the variable and preparation step. TXT files explain the step; `_data.csv` files hold the values and `_gaps.csv` files describe gaps.

The filenames have been simplified for submission. Original column labels inside the tables are unchanged. The original solar workbook is not included.
