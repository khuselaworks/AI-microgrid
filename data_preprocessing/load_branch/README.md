# Load preparation results

Start with `aggregate_load.png` and `aggregation_report.txt` to see the combined household demand. The remaining figures and reports cover raw readings, outliers, missing-value interpolation, cleaning, normalisation and calibration.

Files ending in `_data.csv` contain the values associated with a report. `sentinel_interpolation_report_changes.csv` records changed readings, and `normalisation_report_scaler.json` stores the scaling settings. The source workbook named in the reports is not included.
