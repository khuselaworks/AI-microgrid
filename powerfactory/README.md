# Microgrid control and PowerFactory studies

This section contains the microgrid project and programs for studying the operation of solar generation, battery storage and diesel generators. The work includes scheduling their output and examining how the system responds to disturbances.

- [scripts](scripts/README.md): the PowerFactory project, simulation programs and controller settings.
- [data](data/README.md): demand, PV power and forecast series.
- [mpc_tube](mpc_tube/README.md): saved tables for three operating points and the plotting program.

Start with the scripts guide to run the study. A licensed DIgSILENT PowerFactory installation is needed for network simulations. The standalone controller uses a simplified model and does not replace those simulations.
