# Controller uncertainty at operating points

`tube_OP1.csv`, `tube_OP2.csv` and `tube_OP3.csv` contain saved forecast and controller results at peak demand, largest excess PV, and a low-PV evening respectively. Read the table headers for forecasts, planned actions and uncertainty measures. `mpc_tube_plot.py` is the associated plotting program. It requires NumPy, Matplotlib, controller modules from the sibling scripts folder and configured profile paths; its current defaults assume the older flat layout. See the PowerFactory scripts guide before regenerating results.
