# Saved forecasting runs

Each subfolder is one saved experiment. Start with its `report.txt` and `forecast.png`, then use `metrics.csv` for numerical comparisons. Names are retained as experiment identifiers; labels such as `final` or `improved` do not by themselves establish which benchmark model was selected. Historical paths in configurations describe the original execution environment.
