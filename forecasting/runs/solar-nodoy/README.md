# Saved run: solar-nodoy

This folder contains the recorded `solar-nodoy` experiment. Start with `report.txt` and `forecast.png`. `metrics.csv` summarises errors, `per_step_mae.csv` shows errors across the forecast horizon, and `history.csv` records training progress. `config.json` and `data_summary.txt` describe the settings and input data. `model.pt` contains the trained model. Configuration paths refer to the original run and may need updating for reuse; preserve these files when running new experiments.
