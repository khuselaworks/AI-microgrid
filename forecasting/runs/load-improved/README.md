# Saved run: load-improved

This folder contains the recorded `load-improved` experiment. Start with `report.txt` and `forecast.png`. `metrics.csv` summarises errors, `per_step_mae.csv` shows errors across the forecast horizon, and `history.csv` records training progress. `config.json` and `data_summary.txt` describe the settings and input data. `model.pt` contains the trained model. `predictions.csv` contains the saved predictions. Configuration paths refer to the original run and may need updating for reuse; preserve these files when running new experiments.
