# Input series

These CSV files are included in the repository:

- `aggregate_total_load.csv`: prepared total electricity demand.
- `pv_ac_profile_measured.csv`: measured-profile PV AC power series used in the study.
- `best_load.csv`, `best_pv.csv`: exported model forecasts.
- `reference_load.csv`, `reference_pv.csv`: exported baseline forecasts.
- `perfect_load.csv`, `perfect_pv.csv`: measured future values used as an ideal comparison.

Open the CSV headers to check units and timestamps before using them. The original solar irradiance workbook is not included. These files are working copies for this section; the forecast export layout is explained in the [MPC input guide](../mpc_inputs/README.md).
